Install ISU on Your Phone

Save ISU to your Home Screen so it launches cleanly like a standalone app.

iPhone (Safari) 1. Open this page in Safari.
2. Tap the Share button.
3. Select Add to Home Screen, then tap Add.
Android (Chrome) 1. Open this page in Chrome.
2. Tap Install if prompted, or open the ⋮ menu.
3. Select Install app or Add to Home screen.
